A token launch radar that scores pre-token protocols and ranks them on a static dashboard. It reads a sealed snapshot, scores every protocol with the model in lib/model.ts, and writes the ranked board, a dossier and a static dashboard.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input snapshot.json
```
